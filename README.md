# Express HW1 Redo

This is a simple Express app with five views and more than five routes.

## Node package used

The `/package` page uses `@faker-js/faker`. It displays a generated name, email, city, color, and sentence from the package.

## Web API used

The `/nasa` page uses NASA's Astronomy Picture of the Day API. The request is made in `index.mjs`, on the server side.

## Run locally

```bash
npm install
npm start
```

Then open `http://localhost:3000`.

## Render deployment

- Build command: `npm install`
- Start command: `npm start`
- Environment: Node
